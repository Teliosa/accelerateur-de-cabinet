## Exemple fictif de description

« Un parcours de trois rendez-vous en visioconférence pour préparer une prise de poste de manager. Le premier échange précise les situations prioritaires ; le deuxième permet de préparer un entretien ; le troisième sert à faire le point sur les essais et à ajuster les prochaines actions. »

Le format de cet exemple n’est pas une recommandation universelle. Le prix et les conditions doivent correspondre à votre propre activité.
